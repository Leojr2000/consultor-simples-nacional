🚀 Próximos Passos

Depois de baixar o Excel:

  1. Abra o arquivo "dados_cnpj.xlsx" no seu computador
  2. Vá para a aba "📊 DADOS"
  3. Verifique se os CNPJs estão na coluna A
  4. Salve o arquivo (Ctrl+S)
  5. Abra o terminal/CMD na pasta onde salvou
  6. Execute: python consultor_cnpj.py
  7. Aguarde o processamento
  8. Abra "relatorio_simples_nacional.xlsx" para ver os resultados!

❓ Dúvidas Frequentes

Qual o limite de CNPJs?

Nenhum! Você pode colocar 10, 100, 1000 CNPJs que todos serão consultados.

Quanto custa?

100% GRATUITO! Não há cobrança nenhuma.

Quanto tempo leva?

Depende da quantidade: aproximadamente 5-10 segundos por CNPJ.

Preciso de Python instalado?

Sim, Python 3.6+ e as dependências (pip install -r requirements.txt).

Como instalar Python?

Acesse: https://www.python.org/downloads/ e siga as instruções.
